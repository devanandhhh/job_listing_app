## Features

- 🔍 **Job Listings** — Browse job opportunities with company logo, title, location, job type, and salary/stipend
- 🔎 **Search & Filter** — Live search by title/company, plus job-type filter chips
- 🔄 **Pull-to-Refresh** — Refresh the job list with a swipe
- ⭐ **Favorites** — Save jobs with a tap, view them on a dedicated Favorites screen, swipe to remove — persisted locally with `shared_preferences`
- 📄 **Job Details** — Full description, required skills, experience, and an Apply button
- 🌗 **Dark Mode** — Toggle from the Profile screen, applies app-wide, persisted across launches
- ✨ **Animated Splash Screen** — Branded entry animation
- 🧊 **Liquid Glass Bottom Navigation** — Frosted, floating nav bar between Jobs and Favorites
- 🎨 **Featured Jobs** — Bold gradient card rail highlighting top listings
- 🏗️ **Clean Architecture** — Separated `core`, `data`, and `presentation` layers with Provider for state management
